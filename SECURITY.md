# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in streamboard, please **do not open a public issue**. Instead, email:

**security@usestreamboard.com**

Please include:

- A description of the issue
- Steps to reproduce
- Affected versions / commits
- Any potential impact you've identified

We aim to acknowledge reports within 72 hours and to provide a remediation timeline within one week.

## Supported versions

Only the latest release of each published package (`streamboard` CLI on npm, `@streamboard/sdk` on npm, `streamboard` on PyPI) receives security updates.

## Scope

This policy covers the code in this repository. For issues with the hosted MCP server (`mcp.usestreamboard.com`) or the web app (`usestreamboard.com`), please use the same security email.
